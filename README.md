# سیستەمی کتێبخانەی Al-Shifah Bookshop

سیستەمێکی وێبی سادەیە بۆ بەڕێوەبردنی کتێبخانەکەت، دروستکراوە بە HTML/CSS/JavaScript سادە و بنکەدراوەی **Supabase**.

## ١. دروستکردنی پڕۆژەی Supabase

1. بچۆ بۆ [supabase.com](https://supabase.com) و ئەکاونتێک دروست بکە (بەخۆڕایی).
2. پڕۆژەیەکی نوێ دروست بکە (ناوی بنووسە: `alshifah-library`).
3. لە داشبۆردی پڕۆژەکەت بڕۆ بۆ **SQL Editor** و ناوەڕۆکی فایلی `sql/schema.sql`ی ئەم فۆڵدەرە بخەرە ناوی و **Run** بکە.
   - ئەمە هەموو خشتەکان (books, categories, sales, admin_profile) و هەردوو Storage bucket
     (`book-images` و `avatars`) بۆت دروست دەکات.

## ٢. بەستنەوەی سیستەمەکە بە پڕۆژەکەت

1. لە داشبۆردی Supabase بڕۆ بۆ **Project Settings > API**.
2. **Project URL** و **anon public key** کۆپی بکە.
3. فایلی `js/config.js` بکەرەوە و ئەم دوو نرخە دابنێ:

```js
export const SUPABASE_URL = "https://xxxxxxxx.supabase.co";
export const SUPABASE_ANON_KEY = "eyJhbGciOi....";
```

## ٣. زیادکردنی ئەکاونتی ئەدمین (خۆت)

سیستەمەکە تەنها بۆ ئەدمین کراوەیە، بۆیە پێویستە خۆت وەک بەکارهێنەر زیاد بکەیت:

1. لە داشبۆردی Supabase بڕۆ بۆ **Authentication > Users > Add user**.
2. ئیمەیل و وشەی نهێنی دیاری بکە (بۆ نموونە: `admin@alshifah.com`).
3. ئیتر دەتوانیت بەم زانیارییانە بچیتە ژوورەوەی سیستەمەکە لە پەڕەی «ئەدمین».

> ئەگەر ویستت چەند ئەدمینێکی تر زیاد بکەیت، هەمان هەنگاو دووبارە بکەرەوە — هەموو
> بەکارهێنەرێک لەوێ زیادبکرێت دەتوانێت بچێتە ژوورەوەی سیستەمەکە.

## ٤. کارپێکردنی سیستەمەکە

پێویستە فایلەکان لەسەر سێرڤەرێکی سادە کار بکەن (نەک بە کرتەکردنی راستەوخۆی index.html)،
چونکە جاڤاسکریپت لەم پڕۆژەیەدا بە شێوەی **module** کاردەکات. هەرکامە لەمانە بەکاربهێنە:

**بە VS Code:** پێوەند (extension)ی **Live Server** دابمەزرێنە و کرتە لەسەر `index.html` بکە > Open with Live Server.

**یان بە کۆمانی سادە** (ئەگەر Node.js هەیە):
```bash
npx serve .
```

**یان بلاوکردنەوە بەخۆڕایی لەسەر ئینتەرنێت:** فۆڵدەرەکە بخە ناو
[Netlify Drop](https://app.netlify.com/drop) یان Vercel — سیستەمەکە بەخۆڕایی و
بە لینکێکی گشتی کاردەکات.

## ٥. بەشەکانی سیستەمەکە

| پەڕە | کارەکەی |
|---|---|
| سەرەتا | پوختەی ئەم مانگە: کتێبی زیادکراو، فرۆشراو، قازانج، نرخی جوملە |
| زیادکردنی کتێب | زیادکردنی کتێبی نوێ لەگەڵ وێنە، نرخی فرۆش و جوملە، بڕی کۆگا (بنەڕەت ٩٩٩) |
| فرۆشتنی کتێب | گەڕان بەدوای کتێب و تۆمارکردنی فرۆشتن، لیستی ڕۆژانە و ڕاپۆرتی مانگانە |
| کتێبەکانم | بینین، گەڕان، پاڵاوتن بەپێی جۆر، دەستکاریکردنی کتێب |
| جۆرەکان | زیادکردن و سڕینەوەی جۆری کتێب |
| ئەدمین | چوونەژوورەوە/دەرەوە، گۆڕینی وێنە و ناوی ئەکاونت |

هیوادارم بەکەڵکت بێت بۆ Al-Shifah Bookshop 📚
